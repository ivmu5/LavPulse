# Прогресс анализа в медиатеке

Активные строки пульсируют. По завершении строка сохраняет исходные цвета и оформление, перестаёт пульсировать и показывает размер до/после, длительность и итоговый статус. Размеры измеряются на диске, время включает сам вызов анализа, но не измерение размеров.

Вся история текущего сеанса хранится выше активных задач в порядке завершения. В штатном режиме первый активный трек выравнивается по верхней границе списка, завершённые уходят вверх, новые появляются снизу с анимацией 240 мс. Используется существующий виртуализированный список: обложки и представления создаются только для видимых строк и соседних. Можно прокручивать историю до первого результата без ограничения в шесть записей.

Настройки → Анализ → Прокрутка анализа: возврат к активным трекам через 0–60 секунд после ручной прокрутки (по умолчанию 10 секунд, 0 отключает возврат). Настройка сохраняется независимо от очереди воспроизведения. После окончания анализа автоматический возврат прекращается; история доступна до «Готово».

Параллельность, остановка и индивидуальный пропуск сохранены. Добавлены тесты истории из 2000 результатов, завершения не по порядку, выравнивания и интервала возврата. Визуальная проверка Windows/Android необходима.
