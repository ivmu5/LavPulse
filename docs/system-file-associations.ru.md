# LavPulse как музыкальный проигрыватель по умолчанию

Приложение регистрируется только для поддерживаемых форматов. Выбор приложения остаётся за владельцем устройства: LavPulse не изменяет UserChoice, не сбрасывает ассоциации и не требует административных прав.

## Windows 10/11

1. Запустить LavPulse из его EXE хотя бы один раз. Регистрация выполняется для текущего пользователя.
2. Настройки LavPulse → Воспроизведение → Открытие музыкальных файлов → Назначить плеером по умолчанию.
3. В параметрах Windows выбрать LavPulse для нужных расширений (.mp3, .wav, .ogg, .oga, .flac, .aac, .m4a).

На Windows 11 используется зарегистрированное имя приложения, на Windows 10 — общая страница выбора приложений. Если переход не срабатывает, в Проводнике можно выбрать «Открыть с помощью» → «Выбрать другое приложение» → LavPulse и подтвердить постоянный выбор.

## Android

Открыть музыкальный файл в файловом менеджере, выбрать LavPulse и «Всегда», если этот вариант предлагается оболочкой Android. Поддерживаются также .opus и распространённые альтернативные MIME-типы. Если имя документа не содержит расширения, приложение использует MIME-тип от отправителя или ContentResolver. Доступ к content:// осуществляется по выданному ОС разрешению.

## iOS / macOS (Mac Catalyst)

MP3, WAV и Ogg Vorbis зарегистрированы как поддерживаемые типы документов. На iPhone выбрать LavPulse через меню «Открыть с помощью» в «Файлах»; в версиях iOS с соответствующей функцией можно задать «Всегда открывать в» в свойствах файла. На macOS: Finder → свойства файла → «Открывать в программе» → LavPulse → «Изменить все».

## Поведение

При холодном запуске запрошенный файл получает приоритет над восстановлением старой деки; очередь и медиатека не сбрасываются. При повторном открытии уже текущего трека воспроизведение начинается с начала. При открытии другого файла в работающем приложении используется существующий переход между деками. Если переход уже идёт, запрос ждёт его окончания. На Windows повторный запуск передаёт файл существующему экземпляру.

Если при холодном открытии файл не воспроизводится, прежняя сохранённая дека восстанавливается без автоматического запуска другого трека.

## Проверка на устройстве

- Холодный запуск с сохранённой очередью и новым файлом.
- Открытие того же файла, другого файла во время воспроизведения, из свёрнутого окна, с несколькими файлами.
- Проверить выбор приложения по умолчанию для каждого расширения, отсутствие сброса прежних назначений до согласия пользователя и восстановление после ошибки.
- Проверить Android content:// с обычным именем, без расширения и с альтернативным MIME, iOS Files и macOS Finder.

Автоматический тест проверяет разрешение имени и MIME. Само системное меню, выдача разрешений и реальная активация требуют проверки на устройствах.
