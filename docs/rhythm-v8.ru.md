# Анализ ритма v8

Диапазон гипотез 40–240 BPM. Оценка каждого окна объединяет фазу атак и независимую автокорреляцию положительного изменения энергии трёх диапазонов. Гармонически связанные кандидаты сравниваются по локальным и общим признакам: выбор половинного темпа является эвристикой, а не гарантией определения музыкального метра. Резкие переходы разрешены с фиксированной стоимостью. Публикуются только локально подтверждённые доли; длительные пропуски и выраженные относительные провалы энергии разрывают участок. PredictedBeatFrames хранит гипотезу отдельно; не использовать её для автоматического сведения без проверки.

Диагностика schema 2: predicted-beats.csv, periodicity-scores.csv, section-attempts.csv с решением accepted_with_gaps. Старые анализы v7 пересчитываются; исходные MP3 и очередь не удаляются.

## Воспроизведение отчёта без передачи MP3 или аннотаций в репозиторий

```powershell
dotnet run --project tests/Laveyana.Audio.Playback.Checks -c Release -- --rhythm-report "C:\Reports\LavPulse_Report.zip"
```

Команда повторно запускает C# анализ по сохранённому energy.csv, выводит количество подтверждённых долей, покрытие, совпадения ручных отметок и количество долей внутри помеченных интервалов. Не оценивает ложные доли вне размеченных интервалов и не считает ручные отметки абсолютной истиной. Реальные аудиофайлы и отчёты не включены в git. Полный PCM-анализ и нагрузку на Android нужно проверить отдельно.
