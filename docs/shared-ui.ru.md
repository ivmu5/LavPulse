# Общий интерфейс Laveyana

LavPulse использует NuGet-пакеты версии 0.26.11.3:
- Laveyana.Maui.UI — все MAUI-платформы (Controls).
- Laveyana.Maui.UI.Windows — только Windows (Controls).
- Laveyana.Maui.UI.Android — только Android (приложение).

Общая версия задаётся в MauiPlatforms.props (LaveyanaMauiUiVersion).
Обратных зависимостей от LavPulse или аудиодвижка нет.

## Общие компоненты

- MixerTheme адаптирует UiTheme и UiPaletteCatalog. Цвета визуализации и
  обложек, ключ Preview и сохранённые настройки остаются в LavPulse.
- Стандартная палитра в интерфейсе называется Laveyana; добавлена Mint.
  Сохранённые числовые значения PlayerPalette 0–3 не менялись, Mint = 4.
  Имя PlayerPalette.LavPulse сохранено для совместимости API плеера.
- MixerStyle устанавливает общие семантические ресурсы и сохраняет локальные
  ключи для совместимости. Используются фабрики текста/кнопок и дизайн-токены.
  Локальный ResourceDictionary PlayerView остаётся владельцем темы.
- MainActivity делегирует экран блокировки, системные панели и наблюдение
  за экраном общему Android-пакету. События плеера, обработчики файлов и
  медиасервис остаются в приложении.
- Windows использует общий UiWindowsChrome.Attach на поддерживаемых окнах;
  сохранена реализация из master с резервным заголовком Windows 10, настройками
  размеров, DPI и синхронизацией темы. Нативное поведение проверить на устройстве.

## Ограничения и проверка

Числовой ввод и HSV picker оставлены локальными до проверки паритета
мыши, жестов в прокрутке и вертикального EQ. Не заменять waveform, очередь,
master spectrum и нативные frame loops универсальными контролами без измерений.
Проверить restore/build Windows, Android, iOS и Mac Catalyst; на Android
проверить экран off/on, сворачивание, фокус, блокировку, системные панели,
переоткрытие Activity и работу визуализации. Проверить сохранение всех старых
настроек палитры, Mint, светлую/тёмную/AMOLED темы, F11 и перетаскивание Windows.

Windows: с версии 0.26.11.3 передаём LogoUri = ms-appx:///lavpulse_mark.png, размеры 44×26 DIP и прозрачность заголовка 146/255, панели 230/255. Все четыре кнопки окна принадлежат общей библиотеке; fallback старых Windows остаётся в приложении. Требуется опубликованная версия пакетов и проверка на Windows.
